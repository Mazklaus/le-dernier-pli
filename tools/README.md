# Outils

- `check_assets.py` : vérifie nommage, formats et réglages d'import des assets (lancé en CI avant tout export).
- `export_svg.py` : exporte les SVG de `art/src/` en PNG dans `assets/graphics/` (resvg, Inkscape en secours).
